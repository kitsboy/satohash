# Security Policy

## Supported Versions

Satohash strictly maintains automated security patching on the absolute latest release of the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| v4.x    | :white_check_mark: |
| v3.x    | :white_check_mark: |
| v1.x    | :x:                |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a primary priority for mathematical anchoring systems. If you believe you have found a sensitive edge-case, bypass, or infrastructure flaw:

1. **Do not create a public GitHub issue.** That alerts malicious actors before we can patch it.
2. Email the vulnerability details immediately to **<kimi@giveabit.io>**.
3. We operate on a coordinated disclosure policy. You will receive an acknowledgment within 48 hours and we will work with you to distribute a patch before publicizing the flaw.
