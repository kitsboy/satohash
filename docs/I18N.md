# Internationalization Reference

**Version:** 5.0.0-ELITE · **Updated:** 2026-08-16

Satohash ships seven locales in-repo (not a shared Give A Bit master tree):

| Code | Language |
|------|----------|
| en | English |
| es | Español |
| fr | Français |
| de | Deutsch |
| pt | Português |
| sw | Kiswahili |
| zh | 中文 |

- UI: `src/i18n/translations/*.json`
- Marketing pages: `src/i18n/marketing/`
- Switcher: `src/components/forms/LanguageSwitcher.jsx` (portaled, viewport-clamped)
- SEO: `src/seo/pageMeta.js` + `?lang=`

`npm run i18n:check` fails if keys drift.

Public copy: `public/docs/i18n.md`.
