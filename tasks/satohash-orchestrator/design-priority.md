# Satohash Design Priority Checklist

## Mission
Design is the top priority. The product should feel classy, professional, and sharp. Use strong contrast, clean flow, clear information hierarchy, and subtle illuminated frames for cards and buttons.

## Priority Design Principles
- Make every screen feel purposeful and uncluttered.
- Use a refined palette with high contrast, elegant surfaces, and gold/teal accents only where needed.
- Favor a polished, thin lit frame aesthetic for cards, buttons, panels, and inputs.
- Keep typography readable and scaled, with generous whitespace and clear sections.
- Show the user where to go next with flow-focused layout and minimal noise.

## Core Improvements
1. Consolidate and harmonize color tokens in `src/index.css`.
2. Ensure all primary text and actions meet WCAG AA contrast.
3. Establish a clear CTA hierarchy: primary, secondary, tertiary.
4. Reduce visual clutter and decorative noise on key pages.
5. Simplify navigation to core user journeys and hide advanced items initially.
6. Add consistent thin border/glow framing for cards and buttons.
7. Increase spacing, line-height, and readable font sizes.
8. Strengthen information flow with clearer headings, sections, and labels.
9. Use subtle glass/metal textures only as accents, not as main surfaces.
10. Expose theme switching and keep dark/light themes equally refined.

## Visual Styling Notes
- Buttons should feel premium: sharp edges, thin luminous borders, strong fills, clean text.
- Cards should feel like elevated panels: slight glass, crisp border, soft glow.
- Status badges should be compact and readable, not noisy.
- Navigation should be calm, with distinct active state and muted inactive text.

## Execution Guidance
- Start with the home shell and main action page (`/stamp` or `/vault`).
- Apply the design system globally before editing feature-level pages.
- Validate visual updates with a quick UX review: is the path obvious? is the main action clear? is the page calm?

## Outcome
A polished MVP with design-first clarity: easier flow, stronger contrast, thoughtful layout, and visual elegance.
