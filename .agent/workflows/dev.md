// turbo-all

This workflow automates the common development tasks for Satahash.

1. Ensure all dependencies are installed:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Run linting and tests:
   ```bash
   npm test
   ```

4. Commit changes with a standard message:
   ```bash
   git add . && git commit -m "chore: automated update"
   ```
