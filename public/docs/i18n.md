# Internationalization

**Version:** 5.0.0-ELITE · **Updated:** 2026-08-16 · **Live:** https://satohash.io

Satohash ships **seven locales**. The language control is a single flag/code button in the nav — it opens a portaled panel that stays on screen on phones.

## Locales

| Code | Language | Native |
|---|---|---|
| en | English | English |
| es | Spanish | Español |
| fr | French | Français |
| de | German | Deutsch |
| pt | Portuguese | Português |
| sw | Swahili | Kiswahili |
| zh | Chinese | 中文 |

## How it works

- UI strings: `src/i18n/translations/*.json` plus marketing packs in `src/i18n/marketing/`
- Language switcher writes the locale and updates the URL (`?lang=`)
- `usePageMeta` + `src/seo/pageMeta.js` switch title/description per language
- hreflang targets are listed in the SEO docs

## What is translated

Landing, stamp, verify, pricing, FAQ, glossary, guides, docs chrome, legal headings, and government marketing copy. Template bodies stay English-primary.

## Adding a string

1. Add the key to `en` first.
2. Mirror it in the other six locale files (or the i18n check will fail).
3. Prefer `defaultValue` only as a last resort in JSX.
